# TRABALHO 1 - Computação Gráfica

👟 Tênis Academy - 3D E-commerce
Um protótipo de e-commerce interativo que utiliza Three.js para renderização de modelos 3D em tempo real. O projeto permite aos usuários visualizar modelos de calçados (Nike e Adidas), customizar cores de partes específicas, controlar a iluminação do ambiente e a rotação do produto.

🚀 Funcionalidades
-Visualização 3D Interativa: Rotação, zoom e translação da câmera utilizando OrbitControls.

-Troca de Modelos: Alternância rápida entre modelos de marcas líderes (Nike e Adidas).

-Customização em Tempo Real: Seletor para alterar a cor de partes específicas do tênis (Sola, Base, Cabedal) ou do modelo inteiro.

-Ambiente Realista: Uso de iluminação HDRI (High Dynamic Range Imaging) para reflexos e sombras realistas.

-Controle de Exibição: Sliders para ajustar a intensidade da luz e a velocidade de rotação automática.

-Design Responsivo: A cena se ajusta automaticamente ao redimensionar a janela do navegador.
